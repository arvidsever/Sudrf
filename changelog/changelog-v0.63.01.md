# v0.63.1 — Проверка регистраций по опубликованному УИД

- Принимающий районный суд из `r_juid` проверяется по официальному справочнику региона опубликованной карточки; карточка по-прежнему загружается по опубликованной ссылке и подтверждается по УИД и номеру.
- Разные нативные карточки SUDRF с одинаковым номером дела остаются отдельными регистрациями; точные зеркала по-прежнему дедуплицируются.
- Подтверждённая цепочка регистраций и время последнего полного обновления сохраняются после частичной, пустой и ошибочной выдачи, включая повторное открытие локального хранилища.
- Межрегиональная регрессия использует синтетическую мутацию санитизированной фикстуры #321 в памяти теста; новых live-наблюдений не заявляет. Основание описано в `Tests/SudrfKitTests/Fixtures/issue321_fixture_provenance.md`.
- Схема хранилища и публичные интерфейсы не меняются.

Fixes #156.
