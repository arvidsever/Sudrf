# v0.65.0 (черновик ветки)

В ветке готовится backend-адаптер первого звена мировых судей Москвы для
производств по КоАП. Он использует существующий интерфейс поиска по номеру,
УИД и участнику, но возвращает выдачу как частичную: полнота результата не
подтверждена. Адрес карточки принимается только для HTTPS-хоста `mos-sud.ru`,
числового участка, раздела `admin` и UUID; поля карточки разбираются
существующим парсером Мосгорсуда.

Адаптер пока не подключён к выбору источника, сохранению дела или фоновому
обновлению. Не проверены живой ответ портала, кодировка текущих страниц,
пагинация и семантика пустой выдачи. В модели `CaseCard` нет поля для ссылок на
вложения актов mos-sud, поэтому этот backend-путь их не переносит.

Контракт сверялся с разрешённым reference `aptumyc/sudtudtestbot` на commit
`0ec0cc73bc0b23324a514f8298d858bc62fabb1c`; тестовые HTML полностью
синтетические. Эти сведения не являются подтверждением полной реализации issue
#106.
