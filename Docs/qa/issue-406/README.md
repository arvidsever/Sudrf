## Последовательность хранения

`Issue406RefreshIntegrationTests` проверяет подготовку устаревшей первой инстанции без изменения movement, журнала, подборок, seenAt и времени загрузки; повторная подготовка ничего не меняет. Дисковая последовательность: полный ответ → частичный ответ без своих строк → повторное открытие → полный ответ. Сохраняются исходные инстанции, ID/связи/текст акта и сохранённая проекция панели, ручной подтверждённый срок, история и пользовательские данные; частичный ответ не продвигает время полного успеха.

Распознавание касается только ГПК/КАС. Присоединение не создаёт итог по существу, вступление в силу или срок. Контроли проверяют принимающую регистрацию в тот же день, более раннюю регистрацию с поздним настоящим решением, неоднозначные и отрицательные формулировки, старое будущее заседание и явное самостоятельное возобновление.
