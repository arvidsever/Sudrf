# v0.42.9

## Выгрузка справочников в JSON

Новая подкоманда `sudrf-cli export-directories`: печатает `CourtDirectory`
и `CartotekaRegistry` в JSON.

```bash
swift run sudrf-cli export-directories --what courts     # 9 КСОЮ + Кассационный военный суд
swift run sudrf-cli export-directories --what cartoteki  # 4 кассационные картотеки
```

Приложению эта команда не нужна — она нужна харвестеру правовой базы КСОЮ
([`sudrfpractice`](https://github.com/arvidsever/sudrfpractice)), который ходит
на те же суды из Python. Справочник ведётся здесь и только здесь; харвестер
потребляет выхлоп команды, а не свою копию списка. Иначе два списка
разъедутся — вопрос только в том, когда.

Реализовано подкомандой, а не скриптом в `Scripts/`: файлы там запускаются
как `#!/usr/bin/env swift` и импортировать `SudrfKit` не могут, а `sudrf-cli`
уже собран с ним и с `ArgumentParser`. Соседняя `harvest` решает похожую
задачу — печатает готовые строки для хардкода в `CourtDirectory`.

Поведение приложения не менялось.
