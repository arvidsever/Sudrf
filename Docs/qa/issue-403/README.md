## Область

- Один существующий запрос `router.query` ищет только среди уже загруженных дел:
  номера дела и производств, УИД, стороны и иных участников, судей, суды,
  категории, статьи и подборки. Поиск не обращается к судебным сайтам.
- Подборка, вид производства, стадия, звено и текстовый запрос действуют
  совместно. Четыре вида «Моих дел» получают один отфильтрованный и
  отсортированный набор. Счётчики всей базы в сайдбаре остаются общими;
  заголовки групп показывают количество отобранных дел.
- Карточки группируются по стадиям, производствам и подборкам. Дела без
  определённого вида производства и без подборки получают отдельные группы;
  членство в нескольких подборках сохраняется. Пользовательская подборка
  «Без подборки» не смешивается с одноимённой служебной группой.
- В списке остаётся прежнее поле и кнопка очистки. В групповых видах активный
  запрос виден текстом; его можно очистить или изменить после перехода
  «Изменить в списке». Пояснение совпадения доступно в подсказке и VoiceOver
  без дополнительной строки и изменения высоты карточки. Подсказка ближайшего
  события сохраняется. Для пустого результата во всех видах используется
  одинаковый текст: «Ничего не найдено в загруженных данных по выбранным фильтрам».

## Синтетическая приёмка

Использовать только созданные для теста модели и отдельную временную базу.
Рабочую базу, действующий профиль и персональные данные в артефакты не
включать. Проверить:

1. Поиск по каждому полю, нормализацию регистра, пробелов, дефисов и номера;
   совпадение по нескольким словам и отсутствие ложного совпадения между
   разными делами.
2. Сочетание запроса со всеми структурными фильтрами и сортировкой; одинаковый
   состав результатов в списке и группах, порядок внутри групп.
3. Дело с неопределённым производством, дело без подборки, дело в нескольких
   подборках и пользовательскую подборку «Без подборки».
4. Пустой результат, очистку запроса, возврат к списку с сохранением запроса,
   подсказки совпадения, VoiceOver и подсказку ближайшего события.
5. Измерить отклик фильтра на синтетическом наборе, указав размер набора,
   конфигурацию и способ измерения. Время обработки не объявлять временем
   полного обновления кадра.
