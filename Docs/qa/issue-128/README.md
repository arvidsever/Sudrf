# #128 — сохранённые ложные сроки апелляции

## Основание и границы

Источник последовательностей — [issue #128 и дополнение автора](https://github.com/arvidsever/Sudrf/issues/128), прочитанные 1 октября 2026 года. Санитизированные события в `Issue128DeadlineTests` воспроизводят принятие иска, исправление материалов и отложение по трём примерам. Это синтетические регрессии опубликованного описания, не новый снимок живых судебных карточек.

Первоначальный fallback уже удалён в #70; #125 уточнил выбор вида акта. Здесь проверяется сохранение прежних ложных сроков при подготовке хранилища и обновлении. Новых юридических правил нет.

## Проверяемый контракт

- Без доказанного итогового акта нет нового срока апелляции. Дело без итога остаётся в первой инстанции до и после назначенного заседания.
- Доказанно ложный старый автоматический, подтверждённый или ручной срок становится историческим `.superseded`. Дата, пользовательский статус, основание и identity сохраняются.
- Неизвестный текст, неоднозначная дата/карточка/круг или отсутствие итогового акта только в частичном ответе не дают основания отменить пользовательский срок. Неоднозначная запись требует проверки.
- После появления настоящего акта создаётся самостоятельный расчётный срок. Ложная история не переносит на него подтверждение или ручную дату и не подавляет повторное обновление.
- Исходное движение, акты, подборки, журнал и время загрузки карточки при подготовке сохраняются. Исправление не является новым судебным событием.

## Настоящие экраны на изолированных данных

```sh
bash Docs/qa/issue-128/run.sh
SUDRF_DEADLINE128_QA_OUTPUT="$PWD/Docs/qa/issue-128" \
    /private/tmp/SudrfDeadline128.app/Contents/MacOS/Deadline128
```

В отдельном приложении нажать Command-R. Host использует настоящие `OverviewView`, `MyCasesView` и `CalendarScreen`, но только in-memory store и отдельный bundle ID `ru.sudrf.qa.deadline128`. Production bootstrap, TestFlight, рабочая база и системная индексация Spotlight не используются.

Приёмка сохраняет снимки «Обзора», активных дел и календаря с открытой панелью исторического срока. В данных три санитизированных примера; старый подтверждённый срок 26 сентября 2026 года подставлен специально для проверки исправления.

Для отдельного снимка активного списка запустить host с
`SUDRF_DEADLINE128_QA_SCREEN=cases`. Снимок этого окна получен нативным UI-инструментом:
AppKit cacheDisplay не полностью захватывает динамическую подложку списка.
