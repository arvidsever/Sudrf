# v0.60.3

## Сроки

- Решения и итоговые определения по ГПК и КАС различаются по датированному акту текущего круга. Возврат, отказ в принятии, оставление без рассмотрения и прекращение производства дают частную жалобу; промежуточные акты и противоречивые сведения не создают срок.
- Общая частная жалоба рассчитывается в 15 рабочих дней. Действующее избирательное исключение КАС сохраняется.
- При доказанной смене месячного правила автоматическая дата исправляется, подтверждение снимается; ручная дата сохраняется с новым основанием. Закрытые сроки не возрождаются.

Получены обе первичные карточки из #125: общий срок и избирательное исключение проверяются отдельно по опубликованным реквизитам.
