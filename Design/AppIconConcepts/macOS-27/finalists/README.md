# Finalist app icon concepts

1. `finalist-01-balance-clean.png` — the selected light balance concept with only the oversized translucent U-shaped background loop removed.
2. `finalist-02-dockets.png` — the selected clean parchment dockets concept, unchanged.
3. `finalist-01a-balance-left-heavy.png` — subtle tilt with the left pan lower.
4. `finalist-01b-balance-right-heavy.png` — subtle tilt with the right pan lower.

The active application icon is not changed. These are flattened 1024×1024 concept previews; production artwork should be reconstructed as separate vector layers for Apple Icon Composer.

## Final balance edit prompt

```text
Use case: precise-object-edit
Asset type: final 1024×1024 macOS 27 app icon concept for Sudrf.
Input image: Image 1 is the edit target.
Primary request: remove only the large pale translucent U-shaped background form that starts behind the central post, curves down behind both scale pans, and joins along the bottom behind the pedestal. Replace every part of that U-shaped form with the same clean warm parchment background already surrounding the scales.
Invariants: keep the burgundy central post and crossbar pixel-for-pixel in appearance; keep both terracotta suspension straps; keep both small translucent semicircular pans, including their cream color, rim, size, opacity, and placement; keep the exact symmetry, proportions, margins, parchment color, subtle background shading, and overall flat layered macOS 27 style.
Do not redesign, simplify, thicken, recolor, reposition, crop, or add anything. Do not remove the two actual scale pans. Remove only the separate oversized translucent background loop/U-form behind the scale. No text, symbols, new shadows, watermark, border, or extra objects. One standalone icon.
```

## Subtle imbalance prompts

```text
Use case: precise-object-edit
Asset type: 1024×1024 macOS 27 app icon variation for Sudrf.
Input image: edit target — the selected clean balance finalist.
Primary request: create a very subtle left-heavy balance. Rotate only the horizontal crossbar approximately 2.5 degrees so its left end is lower and its right end is higher. Move the left suspension and left bowl downward with the left endpoint, and the right suspension and right bowl upward with the right endpoint, producing only about a 4% vertical difference between the two bowls. Keep both bowls themselves horizontal, identical in size, and identical in opacity.
Invariants: keep the central post perfectly vertical and centered; keep the pedestal level; keep the exact shapes, thicknesses, colors, parchment background, margins, and calm minimal material treatment. Preserve the same two terracotta triangular suspensions and two cream translucent semicircular bowls. No rear U-shaped form.
Constraints: change only the slight crossbar tilt and corresponding vertical positions of the suspensions and bowls. Do not resize, recolor, thicken, simplify, crop, or add anything. No new shadows, text, symbols, circle, building, folders, watermark, or border. The imbalance must feel gentle and dynamic, never broken or dramatic. One standalone icon.
```

The right-heavy version used the same prompt with all left/right directions mirrored.
