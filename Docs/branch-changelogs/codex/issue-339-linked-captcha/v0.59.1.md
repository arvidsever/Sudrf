# v0.59.1 (черновик)

- При первоначальном добавлении дела и открытии движения из поиска приложение последовательно проходит CAPTCHA каждого связанного суда с включённым автоматическим распознаванием и продолжает исходную проверку.
- Если один суд требует ручного ввода или временно недоступен, проверки остальных продолжаются; уже подтверждённые карточки сохраняются, а частичная проверка не считается полностью завершённой.
- Ручной ввод кода для нескольких судов одного дела остаётся доступен по каждому суду отдельно. Подтверждённая пустая выдача убирает временную заглушку без создания фиктивной карточки.
