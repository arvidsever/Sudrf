# v0.57.5 — результат жалобы КоАП без строки УИД

Промотирован в `changelog/changelog-v0.57.05.md` для выпуска 0.57.5 (166).
Файл сохранён как handoff с подробной проверкой ветки.

- Реквизиты карточки жалобы КоАП читаются и без строки судебного УИД: дата и
  результат рассмотрения больше не теряются из-за отсутствия этой строки.
- Завершённая жалоба выходит из активного «Надзора» после штатного обновления.
  Данные нижестоящего суда не подменяют результат жалобы; неоднозначные реквизиты
  не становятся основанием для уверенного завершения.
- Правила стадий и схема базы не меняются. Истребование дела и датированные
  строки рассмотрения остаются отдельной задачей #256.
