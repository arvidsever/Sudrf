# v0.64.6 (черновик, номер перед выпуском)

- Усилена регрессия добавления прямой ссылки: точная последовательность инстанций, холодное открытие временного хранилища, отметка «просмотрено» и отсутствие дублей событий.
- Подготовлена отключённая по умолчанию живая проверка #339 со штатным CAPTCHA-провайдером и временным логгером. CAPTCHA-хост считается успешным только после более поздней свежей карточки либо проверенной пустой выдачи, без остаточной CAPTCHA или ошибки источника.
- По согласованному контракту изолированы настройки, CAPTCHA-корпус и токены, Spotlight, публикация NSUserActivity и отправка уведомлений. Обычные значения по умолчанию сохранены. Тестовый процесс с NSApp пропускает путь AppRouter, чтобы не менять Dock badge.
- Все тестовые таргеты скомпилированы. Исполнение AppRouter-регрессий, живая проверка и нативная форма ещё не приняты; #339 остаётся открытой.
