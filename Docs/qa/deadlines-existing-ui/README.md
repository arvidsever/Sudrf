# Сроки в существующем интерфейсе

Проверка исправления интерфейса после PR #393/#394. Дата примеров —
3 октября 2026 года. Используются семь санитизированных движений из
`Tests/SudrfAppTests/Fixtures/issue372_movement_examples.json` и синтетические
контроли. Исходные сведения, ограничения и хеш фикстуры описаны в
[доказательствах #372](../issue-372/README.md).

## Нативные экраны

`run.sh` собирает отдельное приложение `SudrfDeadlineExistingUI.app` с bundle ID
`ru.sudrf.qa.deadlines-existing-ui`. Хранилище создаётся только в памяти.
Основное приложение, рабочая база и TestFlight не запускаются.

```sh
bash Docs/qa/deadlines-existing-ui/run.sh
SUDRF_DEADLINE_EXISTING_UI_OUTPUT=/private/tmp/sudrf-ui-screens \
  /private/tmp/SudrfDeadlineExistingUI.app/Contents/MacOS/DeadlineExistingUI
```

Проверки запускаются автоматически. Результат записывается в
`/private/tmp/sudrf-existing-ui-gui-result.txt`; пропущенная нативная проверка
считается ошибкой. Снимки настоящих SwiftUI-представлений: `cases.png`,
`overview.png`. Для осмотра карточки оставьте отдельное окно открытым:

```sh
SUDRF_DEADLINE_EXISTING_UI_SCREEN=card \
  /private/tmp/SudrfDeadlineExistingUI.app/Contents/MacOS/DeadlineExistingUI
```

Карточка содержит нативный прокручиваемый слой: её снимок `card.png` снят через
инструмент интерфейса с окна именно этого проверочного приложения. Снимки
сохранены в [screenshots](screenshots/).

## Проверяемое поведение

- Ближайшая дата выбирается из заседаний и действующих сроков дела и материалов;
  при одинаковой календарной дате первым идёт заседание.
- Несколько материалов сохраняют собственные номера. Непроверенный ключ срока
  не выдаётся за срок основного дела.
- Завершённый основной спор сохраняет стадию, когда в «Дальше» показано событие
  материала. Завершённое производство не показывает старое будущее заседание.
- Материал № 13-630/2026 показывает срок ВС РФ 5 ноября 2026 года; изменение
  пользователем на 12 ноября 2026 года сохраняется и используется в «Дальше».
- Недостаточные сведения дают краткую причину в ячейке и полную текстовую
  подсказку с номером материала. В карточке отсутствуют оба добавленных блока.
- «Обзор», его управление сроками и окно просроченных сроков в 14 дней,
  календарь, вычислитель и формат сохранения не изменены.
