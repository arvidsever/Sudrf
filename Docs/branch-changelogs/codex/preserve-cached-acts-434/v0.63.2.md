# v0.63.2 — Сохранение актов при обновлении карточки

- Если свежий ответ относится к той же проверенной карточке и процессуальному
  уровню, обновление сохраняет отсутствующие в ответе связи с ранее загруженными
  судебными актами, их метаданные и тексты.
- Связь подтверждается источником карточки; совпадения номера дела или хоста
  недостаточно. Свежие данные остаются приоритетными.
- Если тот же ID акта указывает на другую публикацию (ссылка, номер производства
  или хеш содержимого), старый текст и метаданные этой публикации не подмешиваются.

Closes #434.
