# v0.64.2 — Офлайн-приёмка московских цепочек

- Добавлен изолированный офлайн-профиль #322 на санитизированных фикстурах:
  две карточки 1 АСОЮ восстанавливаются через Мосгорсуд, а кассация 2 КСОЮ —
  через Хамовнический районный суд и апелляцию Мосгорсуда.
- Проверены штатный repair/refresh, частичный отказ, повторное открытие
  дискового тестового хранилища, точные ссылки и сохранность журнала и актов.
- Живая проверка текущих карточек и полных ответов источников остаётся
  незавершённой; issue #322 остаётся открытой.
- `TrackedCaseRepairCoordinator` принимает отдельный `CaptchaTokenStore` для
  изолированной приёмки; обычные вызовы сохраняют default `.shared`.
- `CaptchaSettings` принимает отдельный UserDefaults suite для изолированной
  приёмки; проверены сохранение настроек и запись решённого токена без общих
  настроек пользователя.
- Офлайн-профиль передаёт явные providers исполнения и ВС РФ; неиспользуемые
  production clients не создаются при custom service/enforcement closures.

## Изолированная проверка #322 (10 октября 2026 года)

- Подготовлен opt-in частный harness штатных clients→repair→refresh→disk;
  изолированы настройки, токены, sessions, caches, модели и файловые логи.
- Offline проверки redirect policy, точного состава цепочки и disk replay проходят.
- Один живой запуск остановлен на partial кассационной цепочки: сохранены три
  регистрации и пять актов; пустая московская выдача отвергнута текущим parser guard.
- Полная приёмка #322 не завершена: остальные якоря, контроль, repeat/reopen и UI
  остаются открыты. Product parser и интерфейс в этом checkpoint не изменены.
