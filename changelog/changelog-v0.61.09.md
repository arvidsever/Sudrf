# v0.61.9

- Журнал судебных событий сохраняет последнюю обработанную базу отдельно от карточки для показа: неполное обновление больше не поглощает ожидающее подтверждения изменение.
- Подтверждённые изменения разных судов обрабатываются независимо, включая суды Москвы на общем портале. Неполнота своего суда сохраняет его прежнюю базу до успешного подтверждения.
- Сохранение, повторное обновление, перезапуск и объединение записей не дублируют события. Старые записи начинают сравнение с первого подтверждённого снимка без восстановления утраченной истории.

Журнал остаётся в shadow-режиме; переключение ленты, уведомлений и значков — отдельная задача #179.
