# v0.47.2 — честное отображение судебного акта

## Исправлено

- Если обычный суд или мировой участок не опубликовал текст судебного акта,
  Sudrf показывает явное сообщение об отсутствии акта и больше не выдаёт за
  него служебный текст всей карточки дела.
- Для Мосгорсуда опубликованные акты-вложения показываются отдельными
  кликабельными ссылками; сведения карточки дела не подменяют содержимое акта.
- Команда `sudrf-cli card` больше не печатает страницу карточки вместо
  отсутствующего текста судебного акта.

## Совместимость

- Сбор и отображение движения дела, существующие ссылки на файловые акты,
  SwiftData V6 и публичные API не изменены.
- Загрузка и разбор DOC, DOCX и PDF вынесены в #213 после канонизации исходных
  ссылок в #151.

## Проверено

- `swift test`: 913 тестов, 5 пропущено, ошибок нет.
- Регрессии для опубликованного текста, отсутствующего акта, сброса устаревшего
  состояния и файловых ссылок Мосгорсуда.
- SwiftPM build, XcodeGen, Xcode Debug и CI-пакетирование приложения.
