# v0.53.4 — номер принятого производства КСОЮ

## Исправлено

- После присвоения номера производства КСОЮ интерфейс показывает номер из
  квадратных скобок: `88-…`/`88а-…` вместо входящего `8-…`/`8Г-…`/`8а-…`,
  `77-…`/`77У-…` вместо `7-…`/`7У-…`.
- Принятый номер используется в карточке движения, мониторинге, актах и
  календаре. До его появления остаётся входящий номер жалобы.

## Совместимость

- Правило действует только для кассационных инстанций девяти КСОЮ и только
  для согласованных пар индексов. Другие суды и несовместимые пары не меняются.
- Исходный составной номер, URL карточки, идентичность инстанции, навигация,
  поиск и данные SwiftData остаются без изменений.

## Проверка

- Покрыты пары `8→88`, `8Г→88`, `8а→88а`, `7→77`, `7У→77` и
  `7У→77У` с разным регистром.
- Проверены отсутствие второго номера, несовместимая пара, не-КСОЮ,
  Кассационный военный суд и некассационный уровень.
- Календарь хранит сырой номер для открытия дела и отдельную подпись принятого
  номера для месяца, недели и повестки.
