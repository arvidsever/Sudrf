# Sudrf startup-store evidence — v0.46.5 (draft)

> Forecast version. Final number assigned at merge.
> Branch: `codex/issue-77-store-startup-evidence`.

## Что сделано

- В production bootstrap добавлена локальная диагностика `StoreBootstrap`:
  канонический URL store, наличие и размеры `default.store`, `-wal` и `-shm`,
  bundle/app version, schema version, исход открытия, признак нового store и
  число `TrackedCaseRecord` после подготовки.
- Диагностика не пишет номера дел или содержимое записей.
- Ошибка открытия существующего store покрыта regression-тестом: bootstrap
  возвращает `SudrfStoreBootstrapError`, не создаёт чистую пользовательскую
  базу, а исходный store и SQLite-sidecars сохраняются на месте.
- Relaunch-тест проверяет несколько записей и их независимые ключи.

## Границы

- Сигнатура `PersistentStoreBootstrapper.prepareProduction`, `AppBootstrap.State`,
  SwiftData V6 и UI не менялись.
- Retry/quarantine для существующего store не добавлялись; это scope #144.
- Предмиграционный backup остаётся отдельным механизмом; regression-тест
  моделирует последующий relaunch после завершённой миграции и не утверждает,
  что каждый open failure создаёт новую копию.
- Release changelog, app version и build number обновляются только при merge.
