# #355 — штатная отмена загрузки карточки

Проверка 3 октября 2026 года. Сетевые ответы имитируются транспортами тестов;
рабочая база, TestFlight и приложение не запускаются. По указанию пользователя
визуальная приёмка не требуется для этого исправления и не заявляется выполненной.

## Изменение

Обычный суд, мировой участок и mos-gorsud используют одну проверку отмены
(`CancellationError`, его мост в `NSError`, `URLError.cancelled` либо отменённая задача). Статус выдачи
при такой отмене сохраняется. Настоящая ошибка выводится через имеющееся
описание `SudrfError`, явное локализованное описание или понятное сообщение при отсутствии описания. Проверка поколения загрузки
не позволяет прежнему запросу перезаписать новую выбранную карточку.

## Что проверить позднее

В «Поиске» выполнить запрос, выбрать карточку, двойным кликом открыть движение
и вернуться к выдаче. Под формой остаётся «Найдено: N …», без `CancellationError`.
Можно также быстро переключить две карточки и закрыть панель во время загрузки:
статус не должен стать ошибкой отмены. Настоящий сетевой сбой должен давать
понятное сообщение, а повторный выбор карточки — позволять загрузку.

## Автоматические проверки

`SearchResultSelectionTests` проверяет оба вида отмены для каждого из трёх
источников, отмену текущей задачи при ошибке другого типа, запоздалую ошибку
прежнего выбора, реальные локализованные ошибки и понятный fallback для
неизвестного типа. Существующий тест открытия движения дополнен проверкой
неизменности статуса при переходе в движение и возврате.

Профильный набор: 26 тестов, ошибок нет. Регрессия реально воспроизвела мост
Foundation: обычный суд и мировой участок получили `NSError` вместо Swift-типа
отмены. Исправление сохраняет контроль по домену и коду образца CancellationError,
без распознавания по тексту сообщения.
