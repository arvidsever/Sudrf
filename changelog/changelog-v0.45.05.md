# v0.45.5 — судья у каждого дела в календаре

## Исправлено

- В grouped-блоках недельного календаря судья теперь показывается внутри
  строки каждого дела, а общий footer больше не приписывает судью первому
  делу.
- Конфликтные блоки по-прежнему показывают суд, помещение и судью у каждого
  дела.
- Минимальная высота stack-блока учитывает detail-line судьи для каждой строки,
  но остаётся компактной, когда дополнительных реквизитов нет.

## Тесты

- Добавлены узкие контракты форматирования строк grouped- и conflict-блоков и
  проверка высоты stack-блока.
