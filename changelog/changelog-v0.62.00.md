# v0.62.0

- Локальный фильтр «Моих дел» находит сохранённые номера всей цепочки, судей, участников, суды, УИД, категории, статьи и подборки. Несколько слов можно искать по разным реквизитам одного дела.
- Один отбор действует во всех четырёх видах. Причина совпадения доступна в подсказке и VoiceOver; поле остаётся в списке, а карточные виды показывают активный запрос с очисткой и переходом к списку.
- Сохранены результаты без подборки и с неизвестным видом производства. Поиск работает без сети и Spotlight, по подготовленным локальным данным.
