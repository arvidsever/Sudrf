# v0.63.0

- В «Моих делах» можно одновременно выбирать несколько видов производства, стадий и звеньев. Повторный клик снимает выбор; пустая группа показывает всё. Прежний вид строк сохранён.
- Флажок «Показывать завершённые» находится в самом низу боковой панели. По умолчанию видны только активные дела; при включении фильтры учитывают подтверждённую историю всей цепочки, включая материалы. Состояние сохраняется для каждого окна.
- Все четыре представления используют одинаковую фильтрацию и согласованные счётчики. Текущая стадия основного дела определяется отдельно.

Закрывает #324. Фактический вид согласован автором на изолированных данных.
