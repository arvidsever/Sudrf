# v0.57.2

- Полные успешные обновления теперь сохраняют доказанные изменения дела в отдельный append-only shadow-журнал со стабильными идентификаторами; текущие лента, уведомления и badges пока работают по-прежнему.
- Исчезновение, перестановка и неоднозначная перезапись строки не создают юридически значимого события; явное отложение связывается с новой датой только при единственном подтверждённом продолжении.
- Второй уровень offline fixture contract проверяет полный semantic diff на реальных ответах SUDRF, КСОЮ и `msudrf` без сетевых запросов из тестов.
