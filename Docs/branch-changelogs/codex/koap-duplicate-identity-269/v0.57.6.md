# v0.57.6 — объединение связанных карточек КоАП (#269)

Прогноз patch-версии; окончательная версия назначается по порядку merge.

- Найденная по УИД апелляционная или кассационная карточка федерального суда
  связывается с отдельно сохранённым досье через существующую идентичность.
- Частичный отказ другого суда не блокирует подтверждённую связь и не превращает
  обновление в полный успех. Материалы и незагруженные заглушки исключены.
- Старые записи объединяются по сохранённой точной связи при подготовке хранилища
  без обязательного сетевого запроса, с сохранением подборок, истории и времени
  успешного обновления.
