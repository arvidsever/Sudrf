# macOS 27 material refinements

Flattened visual previews with a restrained Liquid Glass material pass. The original finalist geometry and palette remain the design source; dynamic highlights, refraction, translucency, and shadows should ultimately be configured in Apple Icon Composer.

- `balance-left-heavy-macos27.png` — left pan lower.
- `balance-right-heavy-macos27.png` — right pan lower.

## Prompt set

For each edit, preserve the exact source geometry, composition, tilt, proportions, colors, margins, and parchment background. Change only the material treatment:

- Separate the burgundy, terracotta, cream, parchment, and taupe shapes into clearly perceived layers.
- Add narrow crisp top-lit specular highlights along upper and outer edges.
- Add mild edge refraction and controlled translucency.
- Add only short soft shadows between overlapping layers.
- Avoid rounded-square enclosures, outer borders, glow, heavy bevel, chrome, candy-plastic gloss, new symbols, text, and watermarks.

For the balance icons, keep the post vertical, bowls horizontal, tilt unchanged, and do not reintroduce the rear U-shaped form. For the dockets icon, preserve all three folders, their tab positions, and the recessed courthouse geometry.
