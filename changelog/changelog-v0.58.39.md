# v0.58.39 — Устранение priority inversion при копировании cookie CAPTCHA

- Перенесена синхронная запись cookie из callback WebKit на последовательную
  очередь с QoS `.default`; продолжение CAPTCHA-потока вызывается на главном
  потоке после завершения записи.
- Сохранено копирование только cookie точного или родительского домена суда.

Closes #342.
