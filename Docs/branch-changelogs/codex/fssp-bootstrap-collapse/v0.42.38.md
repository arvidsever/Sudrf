# v0.42.38

- Исправлено вертикальное расхождение между Swift- и Python-препроцессорами CAPTCHA ФССП.
- Палитровые PNG ФССП теперь преобразуются по alpha-mask: тёмные цифры больше не проигрывают ярким помехам, из-за которых сеть схлопывалась к одному частотному ответу.
- Bootstrap-тренер использует Adam и 60 эпох вместо недообучавшего сеть короткого SGD-прогона.
- Лаборатория больше не показывает подсказки модели, не достигшей минимальной held-out точности 80%.
- При нулевой exact accuracy тренер выбирает лучший epoch по точности отдельных цифр, а не сохраняет первый случайный epoch.
- Повторное обучение снова привязано к рубежам 300, 400, 500 и далее, даже если предыдущее обучение запустилось с опозданием внутри сотни.
