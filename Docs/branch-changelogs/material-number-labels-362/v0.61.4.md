# v0.61.4

- В «Обзоре» номер материала больше не повторяется под тем же основным номером в ленте изменений и заседаниях. Отдельный номер материала и сообщение о неопубликованном номере сохраняются.
- Исходные номера и идентификаторы остаются доступными для переходов; формат сохранённых данных не меняется.
