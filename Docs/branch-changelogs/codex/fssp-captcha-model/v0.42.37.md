# v0.42.37 — лаборатория CAPTCHA ФССП

- Добавлена отдельная developer-лаборатория `fssp-captcha-lab`: она получает
  свежие CAPTCHA через штатный `FSSPClient`, принимает пятизначный код по Enter
  и сохраняет PNG+код только после подтверждения ответа сервером ФССП.
- После 200 подтверждённых пар лаборатория обучает отдельную bootstrap-модель,
  затем обновляет её после каждых 100 новых пар. Уверенные ответы используются
  для ограниченного автосбора; неуверенные остаются на ручном вводе, а три
  последовательных отказа выключают автосбор.
- Для реальных изображений ФССП 240×80 добавлен отдельный full-frame
  препроцессор. Старый цветовой путь модели ГАС «Правосудие» не изменён.
- Train/held-out теперь закрепляются стабильным SHA-256-бакетом, поэтому рост
  корпуса не переносит прежние изображения между выборками. Лабораторная
  модель и отчёт заменяются только после успешной компиляции и проверки.
- Python-окружение тренировки воспроизводимо и устанавливается только явной
  setup-командой; обычный Sudrf не получает Python-зависимостей или нового UI.
- Production-модель ФССП остаётся выключенной и будет поставляться отдельным
  draft PR только после 2 000 уникальных PNG, 30 ручных фикстур, held-out exact
  accuracy не ниже 97% и не менее 100 уверенных ответов с точностью от 99%.
