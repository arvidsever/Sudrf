# v0.58.38 — Видимая причина отказа восстановления московской цепочки

- Карточка показывает отказ поиска или загрузки нижестоящего московского дела с названием источника, этапом и краткой причиной, включая HTTP-статус.
- Результат восстановления и обновления кассационной карточки отображается раздельно: частичный ответ 2 КСОЮ не скрывает ошибку московского портала.
- После подтверждённого восстановления прежнее предупреждение исчезает; временный отказ сохраняет кэш и действующий порядок повторов.
