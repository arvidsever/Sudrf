# v0.53.3 — движение жалобы в КСОЮ

## Исправлено

- Карточка кассационного суда больше не выглядит пустой до назначения
  заседания: в общую ленту входят опубликованные этапы изучения жалобы.
- Ранняя карточка КоАП без таблицы «Жалобы» показывает опубликованную дату
  поступления из отдельной вкладки «Жалоба».
- Показываются поступление и передача жалобы на изучение, истребование дела,
  оставление без движения, исправление недостатков и итог изучения.
- Даты и результаты берутся только из карточки суда; отсутствующие сведения
  приложение не достраивает.
- Поиск и обновление бережнее работают с общим backend судебных сайтов:
  SUDRF-запросы и redirect-переходы идут последовательно через общую очередь.
  Keep-alive переиспользуется внутри одного origin; перед переходом к другому
  прежняя сессия закрывается. Сохранены таймаут 90 секунд и повторы через
  2/4 секунды.
- Страница техработ с HTTP 200 повторяется тем же общим загрузчиком: форма,
  выдача и карточка получают до трёх попыток в той же сессии и с теми же
  cookies. CAPTCHA и отклонённый код остаются отдельными исходами.
- После успешной выдачи карточка загружается по точному URL строки и сохраняет
  фактические `case_id`, `case_uid`, `delo_id`, `new`, `case_type`, `srv_num`
  и другие параметры источника.
- Если базовая карточка временно недоступна, фоновое обновление продолжает
  известные вышестоящие цели по сохранённому УИД, не затирая последнюю успешную
  базовую карточку.
- При частичном сбое сообщение называет недоступный источник; последнее
  успешное обновление и старые данные не заменяются неполным ответом.

## Совместимость

- Поиск по УИД, загрузка карточки, CAPTCHA и cookies продолжают использовать
  существующий `SudrfClient`; новый сетевой путь не добавлялся.
- Модель данных, SwiftData schema и интерфейс карточки не менялись.
- Специальный путь для `r_juid` не добавлялся; повторное использование всех
  ранее найденных карточек остаётся в отдельной задаче #238.

## Проверка

- Добавлены обезличенные образцы ранней карточки КоАП и таблицы жалоб КСОЮ;
  проверены реальные варианты УПК из 7 колонок и КАС из 10 колонок, несколько
  жалоб и одинаковые даты.
- Проверены прямой UID lookup и продолжение после CAPTCHA без пользовательского
  клика; ручная кнопка остаётся fallback.
- Проверены сетевой таймаут, интервалы повторов, FIFO, ротация origin и redirect,
  отмена запросов, fallback по сохранённому УИД и завершение всей очереди одним
  фоновым воркером.
- Проверены два ответа техработ перед успешной выдачей и карточкой, точный URL
  карточки 3 КСОЮ при наличии идентификаторов, сохранение `sourceURL`, отдельный
  исход CAPTCHA и сообщение с доменом недоступного источника. Живая production-
  проверка вынесена в #241 и не блокирует release.
