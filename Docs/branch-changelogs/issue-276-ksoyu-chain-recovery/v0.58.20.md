# v0.58.20 — Восстановление цепочки из карточки КСОЮ

Исправление #276. Карточка кассационного суда без опубликованного судебного УИД теперь может восстановить цепочку по официально указанной нижестоящей карточке.

- `8Г-162/2019` связывается с делом Фрунзенского районного суда `2-1975/2019`; технический `case_uid` карточки КСОЮ не принимается за судебный УИД.
- Из карточки первой инстанции извлекается УИД `78RS0023-01-2018-009010-02`, после чего общий механизм движения загружает апелляционные и последующие кассационные производства.
- В отслеживании остаётся одна запись с текущим гражданским номером, а `8Г-162/2019` сохраняется как точная связанная карточка и находится по старому номеру.
- Возвращённая жалоба 2019 года остаётся завершённой; более поздняя рассмотренная кассация хранится отдельным производством той же цепочки.
- Сопоставление названий судов допускает только известные служебные территориальные слова, включая различие «Санкт-Петербурга» и «города Санкт-Петербурга», без нечёткого поиска по сторонам или похожим номерам.

Проверка выполнена на санитизированной фикстуре официальной карточки и временной дисковой базе: обычное и повторное обновление, CAPTCHA, временная ошибка, повторное открытие, сохранение подборок, актов, журнала, ручных сроков и прочитанности, отсутствие дублей.
