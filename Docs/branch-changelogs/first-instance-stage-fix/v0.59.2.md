# v0.59.2 — Стадия завершённых дел после пересмотра

- Завершённое основное дело больше не остаётся в «Первой инстанции» из-за ранней частной жалобы или пересмотра отдельного материала.
- Итог самостоятельного материала учитывается и тогда, когда суд опубликовал его только в строке заседания.
- Действительный возврат на новое рассмотрение и назначенное заседание по-прежнему показывают активную стадию.
- Позднее ходатайство после решения не возвращает основное дело в «Первую инстанцию» (проверено на № 2-3767/2014 и № 2-3109/2017).
- Собственная картотека `g1` сохраняет гражданский вид дела № 2-3767/2014: поздняя метка категории КАС не переопределяет источник 2014 года.
- Поздняя апелляция по основному решению завершает стадию, даже если раньше обжаловалось определение: проверено на № 2а-5428/2023 и № 2а-354/2023.
- Нижестоящая карточка без УИД находится по опубликованным суду и номеру, включая второй номер составной карточки; объединение выполняется после проверки единственного источника. Сохранённая ссылка вниз помогает продолжить проверку при временной недоступности вышестоящей карточки.
- При объединении старой регистрации с уже сохранённым основным делом остаётся номер основного дела; повторное отображение одной карточки по её `case_uid` не дублирует движение и сохраняет судебные акты.

Черновик первой очереди: ветка остаётся открытой для проверки остальных дел из фильтра «Первая инстанция».
