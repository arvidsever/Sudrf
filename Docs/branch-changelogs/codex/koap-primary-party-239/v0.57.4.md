# v0.57.4 — основное лицо в делах КоАП

Промотирован в `changelog/changelog-v0.57.04.md` для выпуска 0.57.4 (165).
Файл сохранён как handoff с подробной проверкой ветки.

- Краткое название дела КоАП выбирает привлекаемое лицо по опубликованной роли,
  даже если защитник указан первым. Несколько лиц перечисляются компактно;
  защитник и представитель остаются в полной карточке участников.
- Если привлекаемое лицо не опубликовано, сохраняется имя другого участника
  с явной ролью. Статьи не подставляются к имени чужого участника.
- Сохранённое представление сторон исправляется из имеющегося движения при
  подготовке хранилища без сети и без пересчёта сроков, журнала или времени обновления.
