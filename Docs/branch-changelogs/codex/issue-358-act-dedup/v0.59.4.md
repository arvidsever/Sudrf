# v0.59.4 — Судебные акты без дублей

- Одинаковые опубликованные акты, сохранённые под разными ID, показываются одной строкой в поиске и «Моих делах». Сохранённые ссылки и уведомления продолжают открывать акт.
- Название берётся из заголовка документа, а подпись показывает дату и стадию. Ссылка «Открыть оригинал» ведёт к проверенному файлу или карточке суда.
- Разные акты с противоречащими реквизитами остаются отдельными строками.
