# v0.65.0 — черновик #250

Работа продолжается; фактическая версия назначается перед merge. Фоновый этап
CSV-импорта и его интерфейс ещё не подключены.

## Подготовленный внутренний слой

- Ожидающие запросы SUDRF выбираются по приоритету задачи; равные приоритеты
  сохраняют порядок очереди, активный запрос не прерывается.
- Изолированные регрессии проверяют приоритет, FIFO и отмену ожидания.

Полный результат #250, согласованный интерфейс, проверки progress/отмены и
сохранности импорта должны быть включены в этот черновик после их реализации.
