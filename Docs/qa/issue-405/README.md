# #405 — корневой материал в основной хронологии

Дата: 7 октября 2026 года. Основание: main `0796663`.

Причина: представление отделяло все регистрации `.material`, кроме предыдущих регистраций, хотя общий lifecycle уже распознаёт самостоятельный корневой материал. Экран теперь использует существующий `isRootMaterial` для обеих секций. Тип регистрации, исходные события, идентификаторы и расчёты не меняются.

Корень с датой остаётся в существующей хронологии по первому событию. Единственный доказанный корень без даты ставится перед пересмотрами без выдумывания даты; неоднозначные материалы остаются в отдельной секции. Переход к материалу поддерживается и после его переноса в основную секцию.
