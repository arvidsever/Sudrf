# v0.59.2 (черновик)

- Усилена тестовая приёмка добавления прямой ссылки: проверяются точная последовательность и состав инстанций, повторный импорт после холодного открытия, timestamp отметки «просмотрено» и отсутствие дублей событий.
- Подготовлена opt-in живая приёмка #339 со штатным выбором CAPTCHA-провайдера и временным файловым логгером. До каждого live-запуска требуется утреннее решение по изоляции `NSUserActivity`; до него тесты пути `AppRouter` не запускать.
- Live-проверка считает CAPTCHA-хост успешным только после более позднего подтверждения свежей нативной карточки либо проверенной пустой выдачи, без остаточной CAPTCHA или ошибки источника.
- Модельные тесты не заявляют проверку SwiftUI-формы, буфера обмена или визуального подтверждения.
- Для изолированной opt-in-проверки фабрика солвера принимает внутренний логгер; по умолчанию остаётся `.shared`, выбор CAPTCHA-провайдера не меняется. Единственный отдельный factory-тест прошёл; путь `AppRouter` и live-приёмка остаются на hold из-за нерешённой изоляции `NSUserActivity`.
