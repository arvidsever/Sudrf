# Проверка опубликованных PDF ВС РФ — #345

30 сентября 2026 года. Собственная панель приложения из этой ветки, синтетические
обезличенные данные, отдельное временное хранилище и каталог файлов. TestFlight и
рабочая база не использовались.

## Источник и проверки

- [Карточка](https://www.vsrf.ru/lk/practice/claims/12-36321243) и
  [опубликованный PDF](https://www.vsrf.ru/lk/practice/stor_pdf/2496438) проверены:
  8 страниц, текстовый слой, номер `3-ИКАД25-3-А2`. Байты и хеш описаны в
  [provenance фикстуры](../../../Tests/SudrfKitTests/Fixtures/vsrf_pdf_345_provenance.md).
  Фикстура карточки #340 обезличена; ID опубликованного файла заменён.
- Профильные тесты проверяют путь клиент → проверенная карточка → движение →
  сохранение → список, повторные ссылки, разные документы и производства,
  HTML/повреждённый PDF/лимиты/чужой адрес, скан и противоречащий номер.
- Контроллер проверяет ошибку и повтор, поздний ответ, переключение актов, кэш
  Поиска и запись «Моих дел». Перезапуск отдельного дискового хранилища сохраняет
  текст, происхождение, байты, ID, подборку и журнал событий без повторного запроса.
- Нативное проверочное окно проверяет переключатель «Текст / Оригинал PDF»,
  нижестоящий акт, отдельное окно, скан, загрузку и клик «Повторить». Экспорт
  использует тот же файловый путь записи, что диалог сохранения, и сравнивает
  сохранённые байты с исходным PDF. Системный диалог не автоматизирован.
- Xcode-проект пересоздан, app target собран. Проведено независимое ревью.

```sh
SUDRF_PDF_VISUAL_OUTPUT=/private/tmp/sudrf345-qa \
SUDRF_PDF_NATIVE_SCREENSHOTS=1 \
swift test --disable-sandbox --filter PublishedActViewTests
```
