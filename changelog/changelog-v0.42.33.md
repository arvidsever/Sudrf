# v0.42.33

## Spotlight

- Xcode-сборка использует автоматическую подпись команды Apple Developer и hardened runtime;
  архив проверен экспортом с `Developer ID Application`.
- Индекс переведён с прототипного `default` на именованный Core Spotlight index. Записи
  сохраняются как `CSSearchableItem` со связанным `IndexedEntity`, поэтому поиск работает
  и на macOS 27 beta с известным сбоем пожертвований App Entity.
- Встроенный Spotlight-поиск запрашивает все атрибуты, необходимые для показа результата;
  устранена ошибка связи с helper application и пустая выдача по уже индексированным делам.
- Окно результатов встроенного поиска больше не сжимается до одной строки и показывает
  несколько совпадений с прокруткой.
