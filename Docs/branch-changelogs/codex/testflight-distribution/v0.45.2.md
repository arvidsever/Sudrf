# v0.45.2 — распространение через TestFlight

- macOS-приложение переведено в App Sandbox с минимальными разрешениями на
  исходящие сетевые соединения и выбранные пользователем файлы.
- При первом sandbox-запуске macOS переносит существующую базу SwiftData,
  SQLite sidecar-файлы, настройки и каталог данных Sudrf в контейнер приложения.
- База больше не хранится в корне `Application Support`: приложение
  одноразово переносит её в `Application Support/Sudrf/default.store`.
- Добавлены проверки, не позволяющие расширить миграцию на весь домашний
  каталог или весь `Application Support`.
- Добавлен обязательный для распространения macOS copyright в Info.plist.
- Xcode-архив теперь обязательно содержит все три production CoreML-модели и
  eligibility-отчёт ФССП; CI проверяет их полный состав по SHA-256.
- Перенос существующей SQLite-базы сначала создаёт полную проверенную копию и
  только затем удаляет прежние файлы, не оставляя разделённый набор при ошибке.
