# v0.56.2 — корректная классификация исторических КАС-карточек

- Исторические производства КАС больше не отображаются как гражданские
  при CSV-импорте или добавлении по прямой ссылке, если старая карточка
  открывается через гражданские технические `delo_id/new`.
- Исходные `case_id`, `case_uid`, `delo_id` и `new` сохраняются для загрузки
  опубликованной карточки; меняется только внутренняя классификация.
- Обычные гражданские производства и материалы `13а-*` сохраняют прежнюю
  классификацию.
