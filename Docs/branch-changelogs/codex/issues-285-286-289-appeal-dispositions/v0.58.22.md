# v0.58.22 — Завершённые апелляционные производства

Исправления #285, #286 и #289. Опубликованный итог апелляции больше не оставляет завершённое производство в активной стадии.

- `10-25/2026`: резолютивная часть точно связанного постановления учитывает отмену акта и направление на новое рассмотрение; текущая стадия возвращается в первую инстанцию.
- `5-619/2021 → 12-149/2021`: опубликованное изменение постановления завершает апелляцию КоАП, сохраняет статус «Изменено» и использует единый вычисленный статус законной силы.
- `22-227/2020`: точная формула «СНЯТО ПО ДРУГИМ ОСНОВАНИЯМ» завершает только эту апелляцию, не создаёт срок и не устанавливает законную силу.
- Резолютивная часть извлекается только после последнего структурного маркера и только из акта, прямо связанного с соответствующей инстанцией; мотивировка и промежуточные акты доказательством не являются.
- Более позднее принятие, возобновление или назначение заседания снова делает производство активным. Полный и частичный refresh, повторное обновление и повторное открытие изолированной базы сохраняют акты, журнал, подборки и ручные сроки без дублей.
- Semantic derivation version повышена до 4: старые снимки получают новый baseline без ложного судебного события.

Публичные API, схема хранения, реестр сроков и retry-политика не изменены. Восстановление цепочек #287 и #290 остаётся отдельной задачей.
