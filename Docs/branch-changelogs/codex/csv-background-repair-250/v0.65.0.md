# v0.65.0 — черновик #250

Работа продолжается; фактическая версия назначается перед merge. Фоновый этап
CSV-импорта и прогресс под навигацией подключены; native-приёмка и CI остаются.

## Подготовленный внутренний слой

- Ожидающие запросы SUDRF выбираются по приоритету задачи; равные приоритеты
  сохраняют порядок очереди, активный запрос не прерывается.
- Изолированные регрессии проверяют приоритет, FIFO и отмену ожидания.

## Фоновый этап после сохранения

- Проверка связей продолжается при закрытии отчёта; прогресс и отчёт доступны под навигацией.
- «Остановить» завершает текущую карточку и сохраняет результат перед остановкой.
- Интерактивная карточка получает следующий допуск перед очередной карточкой импорта.
- Знаменатель сохраняет исходные дела, объединение ключей не запускает повторный запрос.
- Повтор после CAPTCHA сохраняет накопленный результат; старая форма остановленной операции не возобновляет её.
- Восемь частных сценариев и независимое ревью пройдены; native-проверка ещё не выполнена.
