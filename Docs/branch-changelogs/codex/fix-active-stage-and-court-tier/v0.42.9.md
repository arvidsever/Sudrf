# v0.42.9 (черновик)

- Уточнено определение текущей стадии: финал первой инстанции сохраняется до
  расчётного срока и семь календарных дней после него, а поздние пересмотры и
  вступление в силу имеют корректный приоритет.
- В «Моих делах» добавлен фильтр текущего судебного звена, включая отдельную
  строку для завершённых производств.
- Исправлена изоляция SwiftData-каталога: его `ModelContext` создаётся на
  executor самого actor.
