# v0.64.3 — карточки заседаний в недельном календаре

Прогноз версии; окончательный patch-номер назначается перед слиянием.

- Карточки заседаний в неделе показывают время и номер дела компактно;
  суд, участники, зал и судья доступны по нажатию.
- При плотной группе дополнительные заседания доступны через «+N».
  Предупреждение о разных судах сохраняется; группа не перекрывает
  заседание материала в следующем часовом интервале.

Приёмка и ограничения: [#337 QA](../../qa/issue-337/README.md).
Нативные снимки требуют отдельного согласования до слияния.
