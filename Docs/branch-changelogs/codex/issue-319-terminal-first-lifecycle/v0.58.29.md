# v0.58.29 — Корректные сроки и завершение первой инстанции

Исправление #319. Итоговые определения больше не проверяются как решения, а
нерассчитанный срок не удерживает завершённое производство активным бессрочно.

- Прекращение гражданского дела получает общий срок частной жалобы по ГПК —
  15 рабочих дней; апелляционный срок на решение применяется только к решению и
  его окончательной форме.
- Правила КоАП выбираются по процессуальной роли карточки. Первоначальное
  постановление, решение районного суда по жалобе и возврат протокола с
  материалами больше не смешиваются; завершённая апелляция мирового судьи не
  получает новый ложный срок.
- Срок КоАП считается только от явно опубликованного получения копии. Для
  односутчного определения требуется точное время; окончание через 24 часа не
  переносится на рабочий день.
- Нерассчитанный срок сохраняется как предупреждение, но lifecycle завершается
  по точному итогу. Семидневная grace-политика действует только для реально
  рассчитанного срока.
- Самостоятельная корневая карточка материала участвует в lifecycle и
  пользовательской проекции; вложенные материалы обычного дела по-прежнему не
  меняют его стадию.
- Точные отказ в принятии административного заявления и возврат протокола с
  материалами КоАП распознаются как terminal outcome. Архивная строка,
  направление копии, промежуточный возврат, передача и присоединение сами по
  себе итогом не являются.
- Более поздний точный итог текущего круга может преодолеть fallback
  неоднозначной апелляции, но принятие, возобновление, remand и будущее
  заседание сохраняют приоритет.
- Semantic derivation поднят с 5 до 6: старые snapshots получают новый baseline
  без ложного события и потери журнала.

Регрессии покрывают реальные номера ГПК, КАС и КоАП, самостоятельные материалы,
полный и partial refresh, повторное обновление и перезапуск временной дисковой
базы с сохранением подборок и ручных сроков. Публичные API, SwiftData-схема,
реестр правил, UI-фильтры и retry-политика не изменены.
