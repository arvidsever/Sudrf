# v0.51.0 — номера производств в «Обзоре»

## Изменено

- В «Заседаниях» и «Ленте изменений» рядом с исходным номером дела теперь
  показывается номер соответствующей апелляционной, кассационной или
  надзорной инстанции, если он известен и отличается от исходного.
- Исторические события используют номер именно своей инстанции; опубликованный
  акт связывается с ней по точному идентификатору, а старые данные без связи —
  только при однозначном совпадении уровня.

## Надёжность

- Старые snapshots без номера в сессии совместимы с новым форматом и не
  создают ложного badge «обновлено» при первом refresh.
- Устойчивые ID заседаний и ленты не зависят от отображаемого номера;
  исполнительные события остаются с исходным номером дела.

## Проверено

- 951 Swift-тест обнаруживается локально; целевая регрессия — 97 тестов без ошибок.
- Визуальная приёмка узких колонок и длинных номеров вынесена в #228 и не
  блокирует выпуск.
