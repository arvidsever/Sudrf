не доказывает побайтовое совпадение с файлом официального портала.

`010b87c4a1a5a598df11b58145c4b48a1af67e602d576787d259c8146a2a5962`.

до 10 мая 2026 года. Дата нижестоящего акта не заменяет дату подачи.

## Изменение и provenance

| Правило | Изменение каталога |
| --- | --- |
| `KAS-CASSATION-REGIONAL-PRESIDIUM` | Новый маршрут, шесть календарных месяцев со дня вступления акта в силу. |
| `KAS-SUPERVISION-CHAIR` | Новый самостоятельный механизм, шесть календарных месяцев со дня вступления обжалуемых актов в силу. |
| `KAS-CASSATION-KSOYU` | Актуальная нумерация пунктов 2–3 части 2 статьи 319 и переходное положение. |
| `KAS-CASSATION-SUPREME-COURT` | Актуальная нумерация пунктов 4–5, включая последующий маршрут после президиума. |

Общий период статьи 318 основан на прежнем RTF. Хеш PDF у четырёх правил
идентифицирует поправку; перечень правил и точное происхождение записаны
в `supplementalSources`. Генератор отклоняет незаявленную подмену,
неподходящий ID правила, неправильный тип и некорректный SHA-256.

Исходный RTF-хеш, результаты морфологического прохода и историческое
`audit.result.coreRules = 20` сохранены. Актуальный каталог: 69 правил,
из них 22 КАС. Длительности и triggers прежних 67 правил не менялись.
Количество policies, dependencies, constraints, exclusions и open questions
не изменилось; содержательные поля сохранены. Revision всех записей КАС
обновлена до 3, в том числе метаданные действующих расчётов.

Новые bindings не добавлены. Расчёт, календарь, выбор производства, API,
формат базы и интерфейс не изменены. Реальные кассационные маршруты требуют
отдельного исправления [#450](https://github.com/arvidsever/Sudrf/issues/450).
Нерешённый вопрос исключаемого периода первой кассации и остальные части
[#222](https://github.com/arvidsever/Sudrf/issues/222) остаются открытыми.
