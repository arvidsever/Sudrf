Дата: 7 октября 2026 года. Основание: main `0796663`.

Причина: строка «Суд» в существующем Grid строилась безусловно, тогда как модель для ВС РФ уже очищает суд и регион. Добавлено условие только к этой строке, без пустой замещающей строки; картотека и прочие поля не изменены.

Проверка модели: переход регионального звена (Москва) → ВС РФ → региональное звено не возвращает старый суд/регион, восстанавливая штатный регион Коми. Профильные `SearchPickerUpdateTests`: 6 тестов, 0 ошибок. Полный набор: 1931 XCTest (25 пропущены: 20 отключённых живых/локальных проверок и 5 модельных тестов до копирования тестовых CoreML-ресурсов), 28 Swift Testing, 0 ошибок. Независимый review не выявил блокирующих замечаний. `xcodegen generate` и собственная неподписанная Xcode Debug-сборка успешны; приложение не запускалось. После копирования игнорируемых CoreML-ресурсов отдельно пройдены все 89 CAPTCHA-проверок (5 штатных пропусков, 0 ошибок), включая ранее пропущенные модельные тесты. Логи сохранены локально в `/private/tmp/sudrf-353/`.
