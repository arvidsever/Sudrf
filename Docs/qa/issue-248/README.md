## Согласованный этап

Обычные и старые федеральные SUDRF-ссылки, Мосгорсуд, региональные мировые
судьи `*.msudrf.ru` и опубликованные производства ВС РФ. Мировые Москвы и

Интерфейс импорта используется прежний, новых экранов нет.

## Подтверждение источников и связей

Импорт сохраняет точный native URL и обновляет карточку через собственный
клиент. Старый федеральный `_uid`-адрес сохраняет `srv_num=2`.
Московский номер сравнивается общей нормализацией, включая ведущие нули;
карточка без собственного опубликованного номера не подтверждает загрузку.

Дело и жалоба ВС РФ связываются только по внутреннему доказательству из
успешно загруженной карточки с ровно одной парой собственных точных адресов,
включая новый формат `claims ↔ claims`. Произвольный `KnownCard` и общий УИД
связи не создают. После сохранения, повторного открытия и повторного импорта
второй карточки остаётся одна запись. Прямые обновления VS используют точный
URL; собственная метка инстанции источника имеет приоритет над номером.

производственные пути, но не подтверждают текущую доступность сайтов.

не использовались; обычное приложение не запускалось. Новых визуальных решений
нет. Формат базы не меняется; добавленные сведения используются существующим
контекстом и графом идентичности.
