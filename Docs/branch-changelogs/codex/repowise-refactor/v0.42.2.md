# v0.42.2 — структурный рефакторинг

## Изменено

- Устранено дублирование настройки локального captcha-солвера между поиском
  и маршрутизатором приложения; параметры по-прежнему читаются непосредственно
  перед каждым распознаванием.
- Общие правила прямых ссылок, построения целей движения и извлечения текста
  HTML перенесены в `SudrfKit` без изменения сетевых fallback-маршрутов.
- Повторяющиеся строки списка судебных актов и обработка результатов поиска
  сведены к общим компонентам и функциям.
- `AppModel.swift` и captcha-интерфейс разделены на файлы по ответственности;
  жизненный цикл `AppRouter` и ручной fallback captcha сохранены.
- Общая отправка UTF-8-запросов выделена только для клиентов Мосгорсуда и
  Верховного суда; особые правила SUDRF, TLS и декодирования не объединялись.
