# v0.42.38 — production-модель CAPTCHA ФССП (draft)

Этот PR намеренно остаётся draft и пока не содержит модельного артефакта.
Инфраструктура сбора и bootstrap-обучения выпущена в v0.42.37; обычный Sudrf
продолжает использовать ручной fallback ФССП.

## Текущий прогресс

- Зафиксированный исходный baseline: 7 уникальных подтверждённых PNG.
- На машине сборщика при создании draft: 12 уникальных PNG 240×80.
- Репозиторные ручные regression fixtures: 0 из 30.
- Production eligibility: не выполнена; `model-captcha-fssp.mlmodelc` не
  публикуется и production-discovery остаётся выключенным.

## Условия перевода из draft

- не менее 2 000 уникальных подтверждённых PNG;
- не менее 30 вручную проверенных regression fixtures, закреплённых за
  held-out и отсутствующих в train;
- exact-string accuracy скомпилированной CoreML-модели не ниже 97% на
  held-out;
- при confidence не ниже 0,90 — не менее 100 принятых held-out прогнозов и
  accuracy не ниже 99%;
- отдельный release asset, SHA-256 manifest и eligibility JSON;
- обе production-модели проверены в собранном `.app`.

До выполнения всех условий PR не должен становиться ready или mergeable как
релиз модели. Bootstrap-модель лаборатории не является production-артефактом.
