# v0.58.10 — черновик

## Исправления

- Поиск апелляции по полному судебному УИД для основных дел КАС, УПК и ГПК, рассмотренных судом субъекта либо окружным/флотским военным судом по первой инстанции (#291, апелляционная часть #76).
- При открытии результата приоритет имеет проверенная точная ссылка суда; отсутствие опубликованного акта не препятствует чтению карточки и движения.
- Пояснение в цепочке описывает поиск по УИД, не обещая успешного обнаружения всех вышестоящих карточек.

## Проверки

Реализация и приёмка продолжаются. Подтверждены официальные пары Коми — Второй АСОЮ и Самара — Четвёртый АСОЮ; военный пример предстоит проверить. Следующий кассационный маршрут и классификация материалов не входят в выпуск. Финальная версия назначается по порядку merge.
