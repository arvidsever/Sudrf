# v0.59.1 — Продолжение проверки связанных судов после CAPTCHA

- При добавлении дела и открытии движения из поиска приложение автоматически
  проверяет каждый связанный суд после распознавания CAPTCHA и повторяет
  исходный запрос. Неудача одного суда не прерывает проверку остальных.
- Уже подтверждённые карточки сохраняются при частичном ответе; подтверждённая
  пустая выдача убирает временную CAPTCHA-заглушку.
- Если требуется ручной код, запрос остаётся в очереди для конкретных дела и
  суда; после ввода проверка продолжается без повторного добавления дела.

Refs #339.
