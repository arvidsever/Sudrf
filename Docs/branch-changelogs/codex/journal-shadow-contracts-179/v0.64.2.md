# v0.64.2 — Проверка совместимости ленты с журналом

- Добавлен тестовый инвентарь совместимости старых ID ленты, переноса отметок
  прочтения и известности, семантических событий и GUID ленты Казначейства.
  Переключение ленты, уведомлений и счётчиков не выполняется.
- Построение текущей ленты выделено в чистую функцию и покрыто проверками
  дат, источников, переходов и прочитанности. Лента продолжает использовать
  прежние данные; переключение на журнал ещё не выполняется.
