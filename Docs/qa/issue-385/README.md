# #385 — открытие сохранённого дела

Проверка 1 октября 2026 года: отдельная ветка от 0.60.0 (219), собственная
Debug-сборка, только синтетические данные. TestFlight и рабочая база для
приёмки не открывались.

## Подтверждение причины

В исходном живом профиле обработчик щелчка `openCase → open → markSeen`
занял 5678 выборок; 4891 из них (около 86%) — полный пересчёт lifecycle из
`reload`. Исходный профиль с локальными сведениями не включён в репозиторий.

## Воспроизводимый замер

`CachedCaseOpeningPerformanceTests` создаёт отдельную базу из 500 дел:
3 инстанции × 6 событий, один текстовый акт на дело. После подготовки
контейнера и первого пересчёта измеряются 20 вызовов настоящего `openCase`.
Подготовка данных, начальный reload и отрисовка окна в время не входят.
Это время синхронного обработчика, а не полная задержка до кадра на экране.

Тот же тест выполнен на родительском коммите `ce25969` и на исправлении.
Результаты и снимки будут добавлены после завершения замеров.

```sh
SUDRF_OPENING_QA_OUTPUT=/private/tmp/sudrf-opening-qa \
SUDRF_OPENING_NATIVE_QA=1 \
swift test --disable-sandbox --filter CachedCaseOpeningPerformanceTests
```

При повторе создаётся новый синтетический файл базы. Публикуются только
обезличенные JSON-метрики и снимки тестового окна; сами базы остаются в `/private/tmp`.

## Сохранение поведения

- В тот же день отметка прочитанности не пересобирает стадии, заседания и сроки.
- Судебные события становятся прочитанными; исполнение читается независимо.
- Открытие по старому locator меняет каноническую запись.
- Ошибка сохранения откатывает отметку; первая загрузка без кэша сохраняется.
- На новый день действует прежний полный пересчёт один раз.
- Новое опубликованное событие возвращает признаки непрочитанного.
- Выбор конкретного акта из ленты и сохранённые данные переживают открытие.

## Границы

Исправление устраняет измеренный общий пересчёт при обычном открытии сохранённого
дела. Первая загрузка без кэша и получение связанных источников остаются в #344.
Первое открытие после смены дня сохраняет необходимый общий пересчёт.
