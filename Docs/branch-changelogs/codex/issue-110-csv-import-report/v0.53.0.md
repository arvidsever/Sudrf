# v0.53.0 — подробный отчёт CSV-импорта

## Добавлено

- Итог CSV-импорта объединён в один прокручиваемый отчёт с отдельными
  секциями импортированных, автоматически исправленных и требующих внимания
  записей.
- Для каждой проблемной записи показываются исходная строка CSV, номер дела,
  суд, категория и понятная причина.
- Проблемные исходные строки можно сохранить как совместимый с импортом CSV,
  исправить и снова открыть через обычную команду импорта.

## Надёжность

- Отчёт различает ошибки формата, неподдерживаемые источники, отсутствие УИД,
  ошибки разбора, временную недоступность, CAPTCHA и проблемы поиска первой
  инстанции, не выдавая сохранённую холодную карточку за потерянное дело.
- Последующий repair ограничен текущим batch и не примешивает результаты
  ранее сохранённых дел; атомарный commit и rollback остаются без изменений.
- После успешного commit отмена больше не скрывает уже сохранённый результат,
  а ошибка post-processing не выдаётся за полный отказ импорта.

## Проверено

- Parser и экспорт покрыты RFC 4180, BOM/CRLF, многострочными полями,
  malformed-входом, round-trip и provenance исходных строк.
- Import/repair regressions покрывают UID grouping, scoped key identity,
  CAPTCHA, ошибки сохранения и отсутствие посторонних записей в отчёте.
- `swift test`: 979 тестов, 5 пропущены, ошибок нет; `swift build`, Xcode
  Debug build и универсальная `SudrfApp.app` 0.53.0/build 150 собраны успешно.
- Вручную проверен прокручиваемый единый отчёт на CSV из 60 проблемных строк;
  экспорт и повторный импорт закреплены автоматическим round-trip тестом.
