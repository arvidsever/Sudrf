# v0.47.1 — корректный выбор военного суда

## Исправлено

- Переключение между гарнизонным, окружным (флотским), апелляционным и
  кассационным военными звеньями сразу очищает несовместимый выбор и загружает
  только суды выбранного уровня.
- Запоздавший ответ предыдущей загрузки больше не может заменить актуальный
  список судов, состояние загрузки или сообщение об ошибке.

## Совместимость

- Источники справочника не изменились: гарнизонные суды отбираются по `GV`,
  окружные и флотские берутся из списка `OV`, а `AV` и `KV` остаются отдельными
  звеньями.
- Обычный picker общих судов, публичные API и форматы хранения не изменились.

## Проверено

- Регрессии конкурентной загрузки, переключения звеньев и точного соответствия
  классификационных кодов военных судов.
- `swift test`: 908 тестов, 5 пропущено, ошибок нет.
- Полный SwiftPM test/build, Xcode Debug и CI-пакетирование macOS-приложения.
