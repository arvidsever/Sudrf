# v0.56.1

## Исправлено

- Исторические производства КАС больше не отображаются как гражданские при CSV-импорте или добавлении по прямой ссылке, если старая карточка открывается через гражданские технические `delo_id/new`.
- При конфликте старой `g*`-картотеки URL с однозначно административным индексом номера выбирается парная `p*`-картотека того же звена, а исходные `case_id`, `case_uid`, `delo_id` и `new` сохраняются для загрузки карточки.
- Учтены административные индексы первой, апелляционной и кассационной инстанций, включая предварительные `9а-*`, исторические `4Га-*` и латинскую `a`.
- Обычные гражданские производства и материалы `13а-*` сохраняют прежнюю классификацию.

## Тесты

- Добавлены регрессии на исторические КАС-алиасы `2а`, `3а`, `9а`, `11а`, `33а`, `66а`, `8а`, `88а`, `4Га`, сохранение исходных URL-параметров и пользовательскую классификацию «Административные (КАС)».
