# v0.46.1 — единый контракт состояния судебного источника (draft)

> Прогнозируемая версия. Финальный номер назначается перед merge.
> Ветка: `architecture-source-outcome-177`.

- Обновление дела теперь типизированно различает пригодный снимок, частичный
  ответ, CAPTCHA, заглушку, транспортную ошибку и ошибку разбора. Пустая
  поисковая выдача считается успешной только при явном подтверждении источника.
- Последняя попытка обновления хранится отдельно от последнего успешного
  получения движения. Ошибка или частичный ответ не продлевают TTL и не
  стирают последнее пригодное состояние дела.
- Диагностический provenance содержит только безопасные сведения об источнике
  и результате; URL-параметры, cookies, токены и CAPTCHA-коды не сохраняются.
- Карточки и выдача mos-gorsud принимаются только при узнаваемой структуре:
  HTTP 200 с maintenance/WAF/неизвестной HTML-страницей больше не считается
  пустым успешным ответом.
- CAPTCHA вышестоящего суда теперь автоматически решается до публикации
  движения: пустая выдача не показывает заглушку, а найденная инстанция сразу
  появляется с данными; ручной ввод остаётся fallback при неуверенном решении.
