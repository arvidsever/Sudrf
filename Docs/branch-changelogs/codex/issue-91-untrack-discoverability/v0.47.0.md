# v0.47.0 — явное снятие дела с отслеживания

## Новое

- В строках «Моих дел», карточных режимах и открытой отслеживаемой карточке
  появилось постоянное меню `…` с действием «Убрать из отслеживания…».
- Перед удалением нативное подтверждение называет дело и предупреждает, что оно
  исчезнет из «Моих дел», обзора, календаря и подборок. Поисковая карточка этого
  действия не показывает.

## Надёжность

- Успешное удаление отменяет только court/enforcement-задачи выбранного дела,
  очищает его ошибки и pending CAPTCHA, но не прерывает общий CAPTCHA solve суда
  для соседних дел.
- Поздние ответы отменённых задач не публикуют callbacks и не восстанавливают
  удалённую запись; generation guard не позволяет старой задаче очистить registry
  новой после повторного добавления.
- При rollback дело и открытая карточка остаются на месте, а общий persistence
  alert позволяет повторить действие.
- Scoped Spotlight synchronization удаляет дело и его акты, не переиндексируя и
  не удаляя соседние записи.

## Совместимость

- SwiftData V6, migration plan, форматы хранения и публичные API не изменились.
- Context menu сохранено как дополнительный путь; Undo, постоянная красная кнопка
  и клавиатурное сокращение не добавлялись.

## Проверено

- `swift test`: 900 тестов, 5 пропущено, ошибок нет.
- Регрессии track → untrack → reload → track, rollback, позднего court/enforcement
  refresh, post-CAPTCHA retry, remap ключа, общей CAPTCHA-задачи и scoped
  Spotlight cleanup.
- SwiftPM build, XcodeGen, Xcode Debug и CI-пакетирование macOS-приложения.
