# v0.59.3 — Стадия акта при открытии дела из поиска

- Движение, открытое из поиска по АСОЮ или КСОЮ, показывает судебный акт на стадии выбранной картотеки. Апелляционные определения 2 АСОЮ по делам № 66а-757/2026 и № 66а-758/2026 больше не подписаны как решения первой инстанции.
- Ранее ошибочно размеченное движение не берётся из кэша при повторном открытии дела.
- При переходе между делами маршрут к вышестоящему суду не берёт УИД предыдущего дела.
