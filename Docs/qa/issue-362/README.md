## Автоматическая приёмка

`OverviewModelTests.testOverviewMaterialNumbersSuppressOnlyDuplicateDisplayLabels`
проверяет оба вида строк, равные номера (включая `№`, NBSP и составной основной
номер), разные номера `2-8236/2025` / `13-4248/2026`, неопубликованный номер,
неизменность ID и непрочитанности. `materialNumber` остаётся доступен для точного
перехода к источнику, фильтра поиска и App Intents. Уведомление использует ту же
подпись без повтора. Календарь, использующий общую модель, получает тот же результат.

При совпадении номеров `secondaryLabel` возвращает `nil`; существующие строки
«Обзора» выводят вторую строку только при непустой подписи. Нового элемента UI нет.

## Что проверить позднее

В «Обзоре» найти событие материала `3/10-16/2026`: номер виден один раз.
То же проверить в колонке «Заседания». У события дела `2-8236/2025` с материалом
`13-4248/2026` должна остаться отдельная строка «Материал № 13-4248/2026».
Переход из строки должен открывать прежнее дело/материал.
