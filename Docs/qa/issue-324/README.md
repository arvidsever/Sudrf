# #324 — изолированная визуальная проверка фильтров

QA entry point использует тот же `MyCasesView`, что и основное приложение, с тремя полностью синтетическими карточками. Он не включает производственный bootstrap, фоновые обновления, реальные карточки, Spotlight или пользовательскую базу.

## Границы изоляции

- Отдельный Xcode target и имя продукта `Sudrf324QA`, bundle ID `ru.sudrf.qa.issue324`, URL scheme `sudrf-qa-324`. Настройки `UserDefaults.standard` относятся к отдельному bundle ID.
- При запуске QA entry point создаёт отдельный SwiftData store в своём sandbox temporary directory, по уникальному пути `sudrf-324-store-<UUID>/qa-only.store`. Этот путь передаётся явно в `SudrfModelContainerFactory.make(inMemory: false, storeURL:)`; production store lookup не используется.
- Данные ограничены двумя активными синтетическими делами и одним синтетическим завершённым делом. Сетевые и фоновые задачи не запускаются.
- Настоящие снимки QA-окна сохраняются средствами UI automation в `screenshots/`. Developer-only меню меняет тему клавишами ⌘L / ⌘D. Bitmap-захват SwiftUI не используется: он не сохраняет системный vibrancy и искажает внешний вид.

## Сборка

`bash Docs/qa/issue-324/build-ui.sh` генерирует отдельный Xcode-проект и собирает его, но не запускает приложение. Единственный ожидаемый bundle:

`/private/tmp/sudrf-324/xcode-qa/DerivedData/Build/Products/Debug/Sudrf324QA.app`

После сборки требуется отдельная визуальная приёмка пользователя. До неё снимки не считаются принятыми и выпуск/слияние не подтверждаются.

## Фактическая проверка 9 октября 2026 года

В собственной Xcode QA-сборке проверены реальные клики: снятие гражданских
оставляет КАС; снятие последнего вида возвращает все активные дела; повторное
добавление гражданских и КАС сохраняет оба выделения. Нижний флажок меняет
выдачу с двух активных на три карточки. Снимки `native-light-off.png` и
`native-light-on.png` показывают настоящее окно, а не HTML-макет.

Независимый Astra review обнаружил и после исправления снял блокер: конфликт
собственного вида производства больше не наследует вид корневого дела.
