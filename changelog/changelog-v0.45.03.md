# v0.45.3 — числовой порядок участков мировых судей

- Участки мировых судей в списке поиска сортируются по номеру из
  классификационного кода (`11MS0001`, `11MS0010`, `11MS0100`), а не по
  названию.
- Некорректные коды не получают номер; остальные суды сохраняют прежний
  алфавитный порядок.

## Проверка

- Добавлены тесты извлечения номеров `1`, `2`, `10`, `100`, malformed-кодов и
  числового порядка участков.
