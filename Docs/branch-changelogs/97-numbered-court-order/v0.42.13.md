# v0.42.13

## Поиск: нумерованные суды идут по номеру

- Кассационные и апелляционные суды ОСЮ в списке звена перечисляются
  «Первый → Второй → … → Девятый», а не по алфавиту, где «Восьмой»
  вставал перед «Вторым», а «Девятый» — перед «Первым».
- Номер берётся из справочника (`TerritorialCourt.number`), а не
  разбирается из названия.
- Звенья без номеров — суды субъектов, районные, мировые — сортируются
  по названию, как раньше.
