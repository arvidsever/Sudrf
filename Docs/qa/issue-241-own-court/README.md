# #241 — проверка собственной регистрации КСОЮ

Дата: 9 октября 2026 года. Основа: `origin/main` `035599ff3e9faf3e1abd6314c848738882cfb707`.

## Подтверждённая причина отдельного дефекта

`MovementService.courtForUIDRegistration` требовал региональный код домена до
проверки совпадения суда. У `3kas.sudrf.ru` нет регионального сегмента, поэтому
корректная строка выдачи по УИД с названием самого суда отклонялась. Предыдущая
регистрация не загружалась, источник оставался неполным.

Региональная проверка перенесена в ветку перехода между разными судами.
Собственная регистрация по-прежнему требует проверенную ссылку, совпадение
`delo_id`, `new`, `case_id`, `case_uid` и названия суда. Последующая проверка
собственной карточки и ограничения межсудебного перехода сохранены.

Это самостоятельная воспроизведённая ошибка кода, **не установленная причина
неполного живого ответа #241**. Доказательства предыдущих живых попыток находятся
в draft PR #404. #241 остаётся открытой до полного пути поиск → карточка →
движение → опубликованный акт → сохранение и повторное открытие.

## Проверки

Синтетические строки и карточки создаются существующим подменённым клиентом
в `Issue94RegistrationHistoryTests`; они не являются ответами живого сайта.
Участники, рабочая база, настройки установленного приложения и TestFlight
не используются. Внешних запросов эта регрессия не выполняет.

- До изменения положительный тест завершился четырьмя ошибками: отсутствовали
  прежняя регистрация, её URL и запрос карточки, а источник был неполным.
- После изменения профильные проверки истории регистраций и межсудебных
  переходов прошли: 13 тестов. Затем добавлена отдельная проверка пяти
  противоречий: название суда, ID карточки, UID карточки, картотека и `new`.
- Независимый review не обнаружил блокирующих замечаний; межсудебная ветка
  сохраняет прежние проверки региона и справочника.
- Генератор registry: `--check` успешен.
- Проект пересоздан, собственная Xcode 27.0 (27A266a) Debug-сборка успешна,
  подпись отключена; приложение не запускалось.
