# v0.42.11

## Упрощение внутреннего устройства

- Удалён неиспользуемый старый пайплайн предобработки CAPTCHA; рабочий
  `Preprocessor` и его регрессионные тесты сохранены.
- Настройки попыток, порога уверенности и preprocessing больше не дублируются
  в отдельной конфигурации солвера.
- Удалены невызванные обёртки диагностики, хранилища и устаревшие файловые
  заглушки без изменения поведения приложения.
