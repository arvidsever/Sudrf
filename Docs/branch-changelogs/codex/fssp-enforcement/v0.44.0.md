# v0.44.0 — Исполнительные производства ФССП

- Блок «Исполнение» проверяет каждый опубликованный судом исполнительный
  документ в Банке данных ФССП по всем регионам и сохраняет найденные
  реквизиты отдельно от данных Казначейства.
- Фоновая проверка не открывает CAPTCHA: карточка показывает, что требуется
  код, а пользователь получает отдельный компактный лист с новой картинкой
  после каждого отклонённого ответа.
- Результат выбирается только при точном совпадении нормализованного номера
  исполнительного документа; неоднозначность и изменение ответа ФССП не
  превращаются в первое приблизительное совпадение.
- Ошибка или CAPTCHA одного источника не стирает последний успешный результат
  другого. Принятые ручные пары CAPTCHA сохраняются в отдельный корпус ФССП
  для последующего обучения локальной модели.
