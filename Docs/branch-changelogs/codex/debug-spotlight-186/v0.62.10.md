  `setEnabled(true)` с полной синхронизацией.
- Фокусные тесты: 20/20. Проверки сборки и оставшаяся native-приёмка описаны в
  [QA #186](../../../qa/issue-186/README.md).

  вместо схемы Sudrf Debug; проверена совместимость генераторов с новой identity.
