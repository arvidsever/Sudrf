# Alpha 0.42.2

## Добавлено

- Компактная карта репозитория с границами таргетов, маршрутами по типам задач,
  сквозными потоками, инвариантами и соответствующими тестами.
- Анализ идей Sudtudtestbot, которые можно адаптировать для локального
  юридического workflow Sudrf без переноса серверной и Telegram-архитектуры.

## Изменено

- Корневые инструкции для агентов направляют широкие и сквозные изменения к
  карте репозитория, не загружая её для локальных правок.
- Каталог строк приложения обновлён по текущему SwiftUI-интерфейсу: добавлены
  извлечённые русские ключи и комментарии Xcode, существующие английские
  переводы сохранены.
- Локальная папка `.reference/` исключена из Git, чтобы внешние репозитории для
  сравнительного анализа не попадали в индекс Sudrf как вложенные gitlink.
