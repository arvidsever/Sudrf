# v0.58.25 — Нижестоящий уголовный материал без УИД

Исправление #290. Апелляционная карточка без судебного УИД восстанавливает официально указанную нижестоящую карточку материала по точному суду и номеру.

- `22-227/2020 (22-8976/2019;)` и материал Октябрьского районного суда Санкт-Петербурга `4-111/2019` сохраняются как одно логическое дело; технические UUID ссылок не принимаются за судебный УИД.
- Общий реестр районных судов теперь направляет индекс `4-…` в картотеку материалов `m`; исправление действует для всех новых карточек такого типа. Официальная вкладка нижестоящего суда задаёт точный суд и номер, а состав участников не используется для подтверждения или опровержения связи.
- Все ранее исключённые уголовные апелляции суда субъекта `u2` без УИД получают одну повторную repair-попытку; остальные terminal-маркеры и обычная retry-политика не меняются.
- Строка и загруженная карточка должны подтверждать один номер и проверяемый источник. Несколько либо нечитаемые точные кандидаты не изображаются единственным совпадением.
- Базовая карточка, апелляционная история, акты, журнал, подборки, прочитанность и ручные сроки сохраняются без дублей; результат «СНЯТО ПО ДРУГИМ ОСНОВАНИЯМ» остаётся завершённым без законной силы и срока.

Публичные API, SwiftData-схема, identity graph, semantic derivation version и lifecycle-правила не изменены.
