# v0.58.37 — Ручное обновление повторяет восстановление цепочки

- Кнопка «Обновить» немедленно повторяет поиск нижестоящей карточки, даже если
  предыдущая попытка назначила задержку или оставила terminal-маркер.
- Если фоновое обновление этого же дела уже идёт, ручная попытка выполняется
  после него один раз, а не теряется при объединении задач.
- Фоновый backoff и окончательные маркеры ремонта остаются в силе; запросы
  не запускаются при одном лишь открытии карточки.

Refs #322.
