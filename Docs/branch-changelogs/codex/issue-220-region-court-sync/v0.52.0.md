# v0.52.0 — синхронизация региона и суда

## Изменено

- В общем поиске выбор региона автоматически выбирает суд субъекта, АСОЮ или
  КСОЮ по его территориальной подсудности.
- Ручной выбор такого суда теперь возвращает регион его места нахождения.
  Для АСОЮ и КСОЮ этот код хранится в справочнике явно, а не выводится из
  списка регионов подсудности.
- У Верховного Суда РФ регион скрыт и очищается; военный поиск остаётся
  общероссийским и без региона.

## Надёжность

- Смена региона или суда инвалидирует прежний scope, а запоздавшее разрешение
  не может вернуть суд из предыдущего выбора.
- Суд субъекта использует существующую точную таблицу «код субъекта → домен»;
  АСОЮ и КСОЮ — проверенные явные коды субъектов места пребывания.

## Проверено

- Целевые acceptance-тесты закрепляют оба направления синхронизации,
  Supreme/military boundary и все явные коды местонахождения.
- Визуальная приёмка вынесена в #230 и не блокирует выпуск.
