# v0.64.2 — Читаемое название суда заседания в календаре

- Для календаря, недели, повестки, дня и связанных подписей заседания
  используется название суда из той же исходной инстанции сохранённого
  движения. Технический код старого снимка больше не подменяет название суда;
  исходный ключ и сравнение конфликтов остаются без изменений.
- Если старый снимок не содержит идентификатора и номера производства, а
  движение допускает несколько исходных карточек одного подтверждённого суда,
  показывается общее название без выбора регистрации. Разные или
  неподтверждённые суды остаются «Суд не установлен».
- Если сохранённая подпись суда пуста, но точный `sourceCardID` имеется,
  название восстанавливается по собственной карточке источника.
- Одинаковый исходный ключ не объединяет подписи разных карточек. Месяц
  показывает короткое название каждой записи, недельная очередь сохраняет
  исходную группировку и выводит разные названия в деталях соответствующих дел.
- Проверена изолированная дисковая фикстура: частичный ответ, закрытие и
  повторное открытие хранилища сохраняют заседания, ID, время, конфликты,
  коллекции и журнал.

Closes #431.
