# Индексы судебных производств

Нормативно-справочная документация Sudrf. Основной документ —
[справочник версии 1.5](court-proceeding-indices.md), подготовленный 12 сентября 2026 года.
Он содержит таблицы, ссылки на источники и машиночитаемый JSON-реестр.

## Состав

| Документ | Назначение |
|---|---|
| [Полный справочник](court-proceeding-indices.md) | Индексы районных судов, судов субъектов, АСОЮ, КСОЮ, военных судов и ВС РФ; петербургские пояснения; территориальные коды и суффиксы ВС РФ |
| [Военно-территориальные индексы ВС РФ](supreme-court-military-territory-codes.md) | Отдельная справка о девяти соответствиях серии 221–229 с официальными контрольными примерами |

Полный справочник — каноническая версия; военный словарь оставлен как самостоятельное
приложение, переданное пользователю. Остальные словари представлены внутри полного
документа (§§15.3–15.5), без дублирования их прежних самостоятельных версий.

В JSON полного справочника: 228 основных индексных записей, отдельный петербургский
слой из 27 записей, 16 конечных судебных кодов ВС РФ, 75 территориальных соответствий
обычных судов и 9 военно-территориальных соответствий.

## Границы использования

Сведения из инструкций, локальной памятки и реконструкция по официальным карточкам
разделены по происхождению. Восстановленные словари не объявляются дословным текстом
отсутствующих нормативных приложений. Исторические периоды действия кодов не следует
придумывать по дате одного контрольного дела.

Территориальный индекс ВС РФ не равен коду региона из УИД. Военный индекс относится
к военной судебной территории, а не обязательно к суду первой инстанции. Конечный
суффикс А/К не определяет сам по себе текущую инстанцию в ВС РФ. Неоднозначное
соответствие 69 не даёт права заменять явно опубликованный суд предположением.

Документы сохраняют все оговорки и исходные сведения версии 1.5. Публикация этой
документации не означает подключения реестра к `CaseIndexClassifier`, `CartotekaRegistry`
или другим компонентам приложения. Изменения классификации и миграции данных требуют
отдельного решения и тестов.
