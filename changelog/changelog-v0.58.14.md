# v0.58.14 — Справочник индексов судебных производств

- Опубликован полный справочник версии 1.5 с JSON-реестром: 228 основных записей и отдельные справочные слои.
- Добавлены оглавление и самостоятельный военно-территориальный словарь ВС РФ. Оба исходных справочника перенесены побайтово из пользовательского архива.
- Документация не подключает реестр к runtime-классификатору; задачи внедрения остаются открытыми.

Проверены UTF-8, JSON-приложения, число основных записей, относительные ссылки README, SHA-256 и чистота diff. Новый юридический анализ не проводился; исторические проверки внутри исходников не выдаются за выполненные при публикации. Локальные Swift-тесты не повторялись, код приложения не менялся.
