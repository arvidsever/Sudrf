# v0.46.0 — удаление пользовательских подборок

- В разделе «Мои дела» пользовательские подборки удаляются через контекстное
  меню с обязательным подтверждением. В подтверждении показано число дел и
  указано, что сами дела останутся отслеживаемыми.
- После удаления подборки её имя исчезает из всех дел и сохранённого списка;
  счётчики и текущий фильтр обновляются, а затронутые дела повторно
  синхронизируются со Spotlight.

## Проверка

- Интеграционный тест покрывает заполненную и пустую подборки, сохранение дел,
  обновление счётчиков и защиту системной строки «Все дела».
- Полный `swift test`: 767 тестов, 5 ожидаемых пропусков, ошибок нет.
