# v0.42.31

## Первый запуск не упирается в ошибку базы

- Если приложение запускается впервые и создание базы срывается — например,
  после падения на предыдущем запуске остались обрывки файлов, — приложение
  убирает их и создаёт базу заново, вместо того чтобы показать ошибку и
  заблокироваться. Терять в этот момент нечего: отслеживаемых дел ещё нет.
- Сообщение об ошибке больше не советует восстановить базу из резервной копии,
  когда никакой копии не существует. Для первого запуска оно теперь объясняет,
  что данных ещё нет и достаточно удалить папку Sudrf и запустить снова.
- Поведение для тех, у кого дела уже есть, не изменилось: при неудачном
  открытии базы приложение по-прежнему останавливается и ничего не трогает.
