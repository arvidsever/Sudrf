# v0.58.3

Исправление #261: повторное изменение судьи, результата или пользовательского срока не прерывает обновление из-за совпавшего идентификатора события. Отдельные повторения получают устойчивые идентификаторы; повторная доставка одного события с другим временем наблюдения не создаёт дубль.

Обновление движения, согласование досье, запись журнала и проекции сохраняются в одной границе отказа. Ошибка журнала до commit откатывает изменения, включая подготовленные удаления дублей. Та же защита применяется к изменению срока и сохранению карточки после CAPTCHA.

Прежние события сохраняются. При объединении независимо накопленных историй одинаковый текст перехода не считается доказательством одного события. Видимая лента остаётся на прежней модели; #179 и #262 не входят в выпуск.

Проверки и окончательная версия будут зафиксированы перед merge.
