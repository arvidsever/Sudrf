## Изменение

Причина дефекта: `pinnedDeadline` возвращал только `first`, а `remainingDeadlines` исключал только его идентификатор. Остальные сроки той же даты попадали под просроченные.

Существующий helper теперь возвращает все записи ближайшего календарного дня. Все строки показаны в существующем ScrollView, верхняя группа подписана количеством. Вторичный порядок: номер дела, вид жалобы, идентификатор. Отбор по lifecycle и 14-дневная видимость просроченных сохранены. Ни правила расчёта, ни сохранение пользовательских дат не изменены.
