# v0.42.38

- Обучение CAPTCHA ФССП переведено на компактную свёрточную сеть с общим классификатором пяти цифр: прежняя полносвязная модель запоминала учебные картинки и не распознавала новые.
- Новый препроцессор выделяет основной цвет цифр, находит всю цифровую строку и нормализует её положение, сохраняя правую часть изображения. Обработка в Swift и Python совпадает и проверяется на реальных подтверждённых PNG.
- Корпус стабильно делится по SHA-256 на обучение, проверку для выбора лучшей эпохи и независимый экзамен. Экзаменационные изображения не участвуют ни в обучении, ни в выборе модели.
- Тренер использует Adam, небольшие искусственные смещения, масштаб и наклон, раннюю остановку и проверяет уже скомпилированную Float32 CoreML-модель. Несовпадение результатов PyTorch и CoreML блокирует публикацию.
- Отчёт модели переведён на строгую схему v2 с отдельными показателями обучения, проверки и независимого экзамена. Старые отчёты автоматически признаются недействительными и вызывают переобучение.
- В лаборатории подсказки разрешаются с 50% точности на независимом экзамене, а автосбор — после не менее десяти уверенных ответов с точностью этой группы не ниже 50%. Автоматический ответ отправляется при уверенности не ниже 50%; после трёх отказов автосбор по-прежнему останавливается до ручного возобновления.
- Продакшен-распознавание остаётся выключенным; его пороги 2 000 PNG, 30 ручных фикстур, 97% полных ответов и 99% точности принятой группы не снижены.
- Повторное обучение привязано к рубежам 300, 400, 500 и далее, даже если предыдущее обучение запустилось с опозданием внутри сотни.
- На текущем корпусе из 600 подтверждённых PNG три контрольных обучения дали 56,1%, 59,6% и 68,4% полностью правильных ответов на независимом экзамене; средняя точность составила 61,4% для полных CAPTCHA и 87,0% для отдельных цифр.
