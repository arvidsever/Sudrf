# v0.58.16 — Процессуальный контекст материалов

Исправление #247. Материал сохраняет самостоятельную роль регистрации, а вид производства определяется отдельно: ГПК, КАС, УПК или КоАП. Подтверждённая связь с основным делом, включая судебный УИД, сильнее неоднозначного индекса. Противоречивые реквизиты оставляют вид неизвестным.

- Единая классификация для списка, фильтров, карточки и расчёта сроков; неизвестные материалы не становятся гражданскими по умолчанию.
- Старые данные уточняются из кэша без сети, объединения записей и повторных событий. Ручные сроки и идентичность сохраняются.
- Сохраняются собственные реквизиты источника, военная ветвь и признак противоречия; старые данные читаются без миграции SwiftData.
- Сроки основного дела не назначаются материалу только на основании кодекса. Новые специальные правила остаются #222, переход к гражданскому делу — #246.
- Раздел «Последние результаты» roadmap возвращён к одной таблице в порядке версий; сведения о проверках перенесены в историю.

Xcode 27 build прошёл. Итоговый протокол тестов дополняется перед PR. Живая приёмка ещё не выполнена: macOS запрещает чтение рабочей базы для резервного копирования. Запущенная копия приложения не заменена. Версия прогнозная; назначается при merge.
