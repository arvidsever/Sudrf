# v0.58.36 — Восстановление московских судебных цепочек

- Карточки 1 АСОЮ `66а-2013/2020` и `66а-4311/2020` связываются с
  официально указанной карточкой Мосгорсуда `3а-3696/2020`. Сходный номер
  за 2019 год не принимается.
- Кассация `8а-7078/2022 [88а-8501/2022]` восстанавливает карточку
  Хамовнического районного суда `02а-0419/2021` по точной ссылке и УИД;
  апелляция Мосгорсуда остаётся отдельной инстанцией той же цепочки.
- Для московских нижестоящих судов используется их собственный портал,
  проверенный URL, суд, номер и опубликованные доказательства связи.
  Отдельно отслеживаемые карточки сливаются без потери истории и
  пользовательских данных.
- Сохранённые ссылки на карточки 1 АСОЮ обновляются напрямую даже без
  судебного УИД; ошибка одного источника не стирает последний успешный кэш.
- Ранее исключённые московские cross-portal записи получают один узкий
  повтор восстановления, после чего действует обычная политика попыток.
