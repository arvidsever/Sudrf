# v0.64.3 — федеральный календарь 2027 года

Прогноз версии; окончательный номер назначается перед слиянием.
Выполненная часть #224/#111, без закрытия оставшегося исторического и
регионального объёма задач.

- Добавлены утверждённые федеральные праздники и переносы 2027 года.
  Рабочая суббота 20 февраля остаётся рабочей, с отметкой сокращённого дня.
- Общий вычислитель теперь продолжает расчёт через границу 2026–2027 годов.
  За пределами подтверждённого покрытия приблизительные даты не создаются.
- Все редакции 2013–2026 годов сохранены. Новых процессуальных правил,
  элементов интерфейса, формата базы или сетевых запросов при расчёте нет.
