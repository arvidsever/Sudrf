# v0.62.4 — настройки: ширина боковой панели (#366)

Прогноз версии; выпуск и номер сборки пока не назначены.

- Минимальная и предпочтительная ширина боковой панели увеличены с 184 до 220 pt: полное название «Экспериментальные» сохраняется. Для каждого пункта добавлена системная подсказка с полным названием; нативный `Label` сохраняет доступное имя для VoiceOver.

## Проверка и оставшаяся приёмка

- `swift build --product SudrfApp` с отдельными scratch/cache каталогами прошёл.
- Изолированный невидимый `NSHostingView` на macOS 27.2 при ширине 720 pt показывает полное название «Экспериментальные». Это проверка оболочки с синтетическим содержимым раздела, не скриншоты работающего приложения.
- Избыточный верхний отступ из #366 на macOS 26 пока не воспроизведён: в изолированном grouped Form первый заголовок расположен примерно в 22 pt от верха содержимого. Общий `.frame(..., alignment: .top)`, `VStack` и `.contentMargins` результат не изменили, поэтому неподтверждённая правка отступов не добавлялась.
- До закрытия #366 нужны скриншоты всех пяти настоящих разделов при 720 pt и стандартной ширине, в светлом и тёмном оформлении на macOS 26; проверить верхний отступ относительно заголовка окна, отсутствие обрезания пунктов и прокрутку длинных разделов. Приёмка верхнего отступа остаётся открытой.
