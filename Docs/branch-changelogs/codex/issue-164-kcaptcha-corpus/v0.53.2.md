# v0.53.2 — проверенный корпус CAPTCHA мировых судей

## Исправлено

- Старый Vision/token-путь больше не пытается распознавать CAPTCHA
  `msudrf.ru`: этот источник остаётся полностью ручным до появления отдельной
  модели, прошедшей независимую проверку.
- После принятого судом ручного кода исходная картинка, точный код и host
  сохраняются только локально для обучения будущей CoreML-модели.
- Повторные картинки дедуплицируются по SHA-256, дополнительные host не
  теряются, а конфликтующая подпись не подменяет ранее подтверждённую.
- Неверные, отменённые и оборванные попытки в корпус не попадают.

## Совместимость

- Форма, картинка, POST и продолжение поиска по-прежнему используют одну
  сессию `SudrfClient` и cookies, реализованную в 0.53.1.
- Корпус никуда не отправляется; SwiftData schema, федеральная CAPTCHA и
  числовые CoreML-модели не меняются.

## Проверка

- `swift build` и полный `swift test`: 1005 тестов, 5 штатно пропущены,
  0 ошибок.
- Проверены accepted/rejected, SHA-дедупликация, конфликт подписи,
  нормализация и сохранение нескольких host, целостность PNG и отсутствие
  сетевого Vision-пути.
- Сгенерирован свежий Xcode-проект; универсальная сборка приложения прошла.
- Self-review и независимый adversarial review завершены; замечания по границе
  accepted и проверке целостности корпуса закрыты тестами.
- Найденный review-ом старый order-dependent тест мирового поиска изолирован:
  он теперь дожидается resolver перед подстановкой fixture и проходит отдельно.
