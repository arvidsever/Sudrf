# v0.65.0 — черновик #68

Прогноз для будущей полной функции Source Health; версия не назначена.
Экран и подключение индекса к операциям ещё не реализованы; issue остаётся открытой.

## Подготовлено

- Общая классификация сетевых отказов для клиента и диагностики: TLS,
  DNS, тайм-аут, потеря соединения, отмена и прочие сетевые ошибки.
- Ежедневная проверка порталов правильно относит отказ клиентского
  сертификата к TLS. Проверка доверия и повторы клиента сохраняются.
- Категорию прежней сохранённой ошибки можно получить из её числового
  кода без изменения формата базы или сохранения текста ошибки.
- Чистая модель отдельно хранит последнюю попытку, подтверждённый успех
  и ошибку каждого сайта; индекс сохраняет только эти проверенные факты.
  Модель и индекс пока не подключены к runtime-операциям.
- Добавлен атомарный локальный JSON-индекс с повторной проверкой host и
  безопасных метаданных при чтении; состояние пока не подключено к операциям.
- CAPTCHA candidate-логи (старые и новые) ограничены 50 файлами с удалением
  самых старых; остальные файлы в папке диагностики не затрагиваются.

## Согласованные решения

- Source Health размещается в существующих настройках; безопасные сведения
  показываются в приложении, raw-файлы открываются через Finder.

## Осталось

- Уточнить, может ли индекс вытеснять состояние host, который всё ещё
  относится к отслеживаемому делу. До ответа индекс не забывает host.
- Подключить подтверждённые исходы операций, краткие сообщения и согласованный UI.
- Выполнить полные проверки и визуальную приёмку перед выпуском.
