# v0.42.27

## Приложение больше не падает при обновлении дела

- Собранное приложение вылетало при первом же обновлении карточки дела, если
  запускалось не из папки разработки: в .app не попадали ресурсные файлы —
  в частности справочник судов со старым поисковым интерфейсом. Теперь они
  лежат внутри приложения, и оно работает из любой папки.
