# #414 — завершённая апелляция и короткое название нижестоящего суда

Дата проверки: **7 октября 2026 года**. Основание: origin/main `ed213b9ae20edfbf714167cab8a5a78c64803ac4`, диагностика текущей Xcode Debug 0.62.2 (239).

## Причина и граница

`CaseLifecycleResolver.courtTitlesAgree` делегировал сравнение региональному matcher, не допускающему городской хвост. Пара «Эжвинский районный суд» / «Эжвинский районный суд г. Сыктывкара Республики Коми» отвергалась. Поздняя завершённая обычная апелляция не проходила проверку принадлежности корневой карточке; консервативный fallback оставлял первую инстанцию.

Общий внутренний matcher теперь допускает ровно одну сокращённую сторону без хвоста и другую с тем же базовым названием, явным городом и подтверждённым регионом домена. Отображаемый ключ без региона сам по себе не используется. Сетевой поиск исходного суда не расширен; юридические правила, публичные API, формат базы и UI не менялись.

| Корневая регистрация | Обычная апелляция | Результат |
| --- | --- | --- |
| 2а-1139/2020 ~ М-1009/2020 | 33а-668/2021 | Принят отказ от иска; производство прекращено |
| 2а-1145/2020 ~ М-1010/2020 | 33а-1048/2021 | Решение оставлено без изменения |
| 2а-53/2021 (2а-1142/2020;) ~ М-1007/2020 | 33а-4017/2021 | Решение оставлено без изменения |

Это завершение рассмотрения цепочки, без выдуманного `inForce` или срока. Предупреждение `legalForce` остаётся: по выбранной автором границе его диагностика записана отдельно в [#222](https://github.com/arvidsever/Sudrf/issues/222#issuecomment-6025783341).
